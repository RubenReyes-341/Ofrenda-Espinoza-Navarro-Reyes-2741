# Ofrenda 3D – Trajinera de Xochimilco (Three.js)

Proyecto de visualización 3D desarrollado con Three.js que representa una escena inspirada en una ofrenda de Día de Muertos sobre una trajinera de Xochimilco, utilizando figuras tridimensionales, iluminación y ambientación visual.

La escena permite al usuario recorrer libremente el entorno mediante controles de cámara, explorando los distintos elementos y detalles del escenario.

---

## Objetivo del proyecto
Aplicar los conocimientos adquiridos en la creación y distribución de escenarios tridimensionales, incluyendo el uso correcto de cámaras, iluminación, animaciones básicas y navegación dentro de un entorno 3D en el navegador.

---

## Tecnologías utilizadas
- JavaScript
- Three.js
- OrbitControls
- HTML5
- CSS3

---

## Funcionalidades
- Renderizado de una escena 3D completa en el navegador
- Navegación libre mediante OrbitControls:
  - Zoom in / Zoom out
  - Paneo
  - Rotación y tildeo de cámara
- Iluminación aplicada a objetos específicos para resaltar detalles
- Animaciones básicas de rotación
- Uso de imágenes aplicadas en planos tridimensionales para ambientación

---

## Aprendizajes
- Creación de un entorno 3D de gran escala para exploración del usuario
- Uso adecuado de luces para resaltar elementos específicos de la escena
- Construcción de estructuras complejas utilizando geometrías 3D básicas
- Organización y vinculación de múltiples archivos y componentes dentro de un proyecto Three.js
- Integración de código desarrollado por distintos integrantes del equipo
